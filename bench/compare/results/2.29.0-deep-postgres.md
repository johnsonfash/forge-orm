## What forge and raw sent

### `pk`

findUnique user by primary key

**forge** (1 round trip)

```sql
SELECT "users"."id", "users"."email", "users"."name", "users"."role", "users"."active", "users"."created_at", "users"."prefs" FROM "users" WHERE "users"."id" = $1
```

**raw** (1 round trip)

```sql
SELECT id, email, name, role, active, created_at, prefs FROM users WHERE id = $1
```

### `unique_email`

findUnique user by unique email

**forge** (1 round trip)

```sql
SELECT "users"."id", "users"."email", "users"."name", "users"."role", "users"."active", "users"."created_at", "users"."prefs" FROM "users" WHERE "users"."email" = $1
```

**raw** (1 round trip)

```sql
SELECT id, email, name, role, active, created_at, prefs FROM users WHERE email = $1
```

### `filter_offset`

users role=USER AND active AND created_at in range, ORDER BY created_at DESC, id; OFFSET 20 (2 on tiny seeds) LIMIT 20

**forge** (1 round trip)

```sql
SELECT "users"."id", "users"."email", "users"."name", "users"."role", "users"."active", "users"."created_at", "users"."prefs" FROM "users" WHERE ("users"."role" = $1 AND "users"."active" = $2 AND "users"."created_at" >= $3 AND "users"."created_at" < $4) ORDER BY "users"."created_at" DESC, "users"."id" ASC LIMIT 20 OFFSET 20
```

**raw** (1 round trip)

```sql
SELECT id, email, name, role, active, created_at, prefs FROM users WHERE role = $1 AND active = $2 AND created_at >= $3 AND created_at < $4 ORDER BY created_at DESC, id ASC LIMIT 20 OFFSET 20
```

### `cursor`

posts ORDER BY id, 20 after a cursor id (exclusive)

**forge** (1 round trip)

```sql
SELECT "posts"."id", "posts"."author_id", "posts"."title", "posts"."body", "posts"."status", "posts"."views", "posts"."version", "posts"."published_at", "posts"."created_at", "posts"."meta" FROM "posts" WHERE "posts"."id" > $1 ORDER BY "posts"."id" ASC LIMIT 20
```

**raw** (1 round trip)

```sql
SELECT id, author_id, title, body, status, views, version, published_at, created_at, meta FROM posts WHERE id > $1 ORDER BY id LIMIT 20
```

**raw** (1 round trip)

