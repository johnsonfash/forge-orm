## What forge and raw sent

### `pk`

findUnique user by primary key

**forge** (1 round trip)

```sql
find {"find":"users","filter":{"_id":"u_000001"},"limit":1}
```

**raw** (1 round trip)

```sql
find {"find":"users","filter":{"_id":"u_000001"},"limit":1,"singleBatch":true}
```

### `unique_email`

findUnique user by unique email

**forge** (1 round trip)

```sql
find {"find":"users","filter":{"email":"bob.1@bench.dev"},"limit":1}
```

**raw** (1 round trip)

```sql
find {"find":"users","filter":{"email":"bob.1@bench.dev"},"limit":1,"singleBatch":true}
```

### `filter_offset`

users role=USER AND active AND created_at in range, ORDER BY created_at DESC, id; OFFSET 20 (2 on tiny seeds) LIMIT 20

**forge** (1 round trip)

```sql
find {"find":"users","filter":{"$and":[{"role":"USER"},{"active":true},{"created_at":{"$gte":"2025-01-01T10:00:00.000Z"}},{"created_at":{"$lt":"2025-02-11T06:00:00.000Z"}}]},"sort":{},"skip":20,"limit":20}
```

**raw** (1 round trip)

```sql
find {"find":"users","filter":{"role":"USER","active":true,"created_at":{"$gte":"2025-01-01T10:00:00.000Z","$lt":"2025-02-11T06:00:00.000Z"}},"sort":{},"skip":20,"limit":20}
```

### `cursor`

posts ORDER BY id, 20 after a cursor id (exclusive)

**forge** (1 round trip)

```sql
find {"find":"posts","filter":{"_id":{"$gt":"p_0000100"}},"sort":{},"limit":20}
```

**raw** (1 round trip)

```sql
find {"find":"posts","filter":{"_id":{"$gt":"p_0000100"}},"sort":{},"limit":20}
```

### `count_filter`

count posts status=PUBLISHED AND views >= 500

**forge** (1 round trip)

```sql
aggregate {"aggregate":"posts","pipeline":[{"$match":{"status":"PUBLISHED","views":{"$gte":500}}},{"$group":{"_id":1,"n":{"$sum":1}}}],"cursor":{}}
```

**raw** (1 round trip)

```sql
aggregate {"aggregate":"posts","pipeline":[{"$match":{"status":"PUBLISHED","views":{"$gte":500}}},{"$group":{"_id":1,"n":{"$sum":1}}}],"cursor":{}}
```
